ranger-bridge: wire ModCompat (6 of 9)

Publishes the three compatibility-guard outcomes (SuppressStandBy, SuppressSlicing,
ClearsStandByFlag) as tags naming which mod, if any, is responsible for each -
"suppressed, and by whom" rather than a bare boolean, since AppendDetected's own
list already carries the who and duplicating it as a raw true/false would need
cross-referencing to answer the same question. Called from the same site as
AppendDetected in Telemetry.cs's Flush() (the one place detection is already
forced regardless of caller order, per ModCompat's own doc comments on the
Awake-time hazard). Additive only - no NDJSON field changes, no behavior change.
Both mods build clean; Release rebuild verified by artifact timestamp.
